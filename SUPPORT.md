# Support

Where to go with questions, bugs, and ideas.

| I want to… | Where to go |
|---|---|
| Report a bug | [Open a bug report](https://github.com/camilesing/CodeSmith/issues/new?template=bug_report.md) |
| Request a feature | [Open a feature request](https://github.com/camilesing/CodeSmith/issues/new?template=feature_request.md) |
| Ask a usage question | Search the [docs](docs/) first; if unresolved, open an issue |
| Report a security vulnerability | **Do not open a public issue** — follow [SECURITY.md](SECURITY.md) |
| Contribute code or docs | Read [CONTRIBUTING.md](CONTRIBUTING.md) |
| Report a conduct issue | See [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md) |

## Before you file

- Check the [CHANGELOG](CHANGELOG.md) — it may already be fixed in a newer release (`codesmith update` pulls the latest).
- Search [existing issues](https://github.com/camilesing/CodeSmith/issues) to avoid duplicates.
- For bugs, include: `codesmith --version` output, OS and terminal, provider and model, a config with secrets redacted, and steps to reproduce.
