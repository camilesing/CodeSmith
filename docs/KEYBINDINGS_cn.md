# 键位绑定

这是 TUI 识别的所有键盘快捷键的权威目录。绑定按**上下文**分组——即它们在哪种焦点或模态状态下触发。列在"Composer"下的绑定只在输入框获得焦点时生效；列在"Transcript"下的只在会话记录获得焦点时生效；以此类推。

绑定（目前）尚不支持用户自定义——已列入未来版本计划（#436、#437）。本文档就是未来配置文件覆盖所引用的契约。

## 全局（任意上下文）

| 按键组合              | 功能                                                           |
|----------------------|---------------------------------------------------------------|
| `F1` 或 `Ctrl-/`     | 切换帮助浮层                                                  |
| `Ctrl-K`             | 打开命令面板（斜杠命令查找器）                                 |
| `Ctrl-C`             | 取消当前回合 / 关闭模态框 / 先武装再确认退出                   |
| `Ctrl-D`             | 退出（仅当输入框为空时）                                       |
| `Tab`                | 循环切换 TUI 模式：Plan → Agent → YOLO → Plan                  |
| `Shift-Tab`          | 循环切换推理强度：off → high → max → off                       |
| `Ctrl-R`             | 打开恢复会话选择器                                             |
| `Ctrl-L`             | 刷新 / 清屏                                                   |
| `Ctrl-O`             | 为选中/进行中/最近的工具工作打开 Activity Detail，或在输入框为空时打开思考块的完整推理时间线 |
| `Ctrl-Shift-E` / `Cmd-Shift-E` | 切换文件树侧栏                                        |
| `Alt-G`              | 输入框为空时将转录滚动到顶部                                   |
| `Alt-!` / `Alt-@` / `Alt-#` / `Alt-$` / `Alt-0` | 聚焦 Work / Tasks / Agents / Context / Auto 侧栏 |
| `Ctrl-Alt-0`         | 隐藏右侧栏                                                     |
| `Esc`                | 关闭最上层模态框 · 取消斜杠菜单 · 关闭 toast 提示              |

## Composer（输入框）

编辑即将发送的消息。

| 按键组合                     | 功能                                                    |
|-----------------------------|---------------------------------------------------------|
| `Enter`                     | 发送消息（或运行斜杠命令）                              |
| `Alt-Enter` / `Ctrl-J`      | 插入换行但不发送                                        |
| `Ctrl-U`                    | 删除到行首                                              |
| `Ctrl-W`                    | 删除前一个单词                                          |
| `Ctrl-A` / `Home`           | 移动到行首                                              |
| `Ctrl-E` / `End`            | 移动到行尾                                              |
| `Ctrl-←` / `Alt-←`          | 向后移动一个单词                                        |
| `Ctrl-→` / `Alt-→`          | 向前移动一个单词                                        |
| `Ctrl-V` / `Cmd-V`          | 从剪贴板粘贴（括号粘贴模式也会自动处理）                |
| `Ctrl-Y`                    | 从 kill 缓冲区粘贴（yank）                              |
| `↑` / `↓`                   | 循环浏览输入框历史（也可用于选择弹窗/附件条目）         |
| `Ctrl-P` / `Ctrl-N`         | 循环浏览输入框历史（另一种方式）                        |
| `Ctrl-S`                    | 暂存当前草稿（`/stash list` 查看，`/stash pop` 恢复）   |
| `Alt-R`                    | 搜索提示历史（Alt-R 退出）                              |
| `Tab`                       | 斜杠命令 / `@` 提及补全（感知弹窗）                     |
| `Ctrl-O`                    | 输入框获得焦点时为其草稿打开外部编辑器                  |

### `@` 提及

输入 `@<partial>` 会打开文件提及弹窗。`↑`/`↓` 循环选择条目，`Tab` 或 `Enter` 确认。`Esc` 隐藏弹窗。自 v0.8.10 (#441) 起，补全结果按提及的 frecency 重新排序——你经常且最近提及的文件会浮到顶部。

### `#` 快速添加（记忆）

当 `[memory] enabled = true` 时，输入 `# foo` 并按 `Enter` 会将 `foo` 作为一条带时间戳的列表项追加到你的记忆文件中，*不会*发送回合。参见 `docs/MEMORY.md`。

## Transcript（会话记录获得焦点时）

| 按键组合              | 功能                                                  |
|----------------------|-------------------------------------------------------|
| `↑` / `↓` / `j` / `k`| 滚动一行（v0.8.13+：输入框为空时裸方向键也可滚动）    |
| `PgUp` / `PgDn`      | 滚动一页                                              |
| `Home` / `g`         | 跳到顶部                                              |
| `End` / `G`          | 跳到底部                                              |
| `Esc`                | 将焦点返回输入框                                      |
| `y`                  | 将选中区域复制（yank）到剪贴板                        |
| `v`                  | 开始 / 扩展可视选择                                   |
| `o`                  | 打开光标下的 URL（支持 OSC 8 的终端）                 |

## 侧栏（侧栏获得焦点时）

| 按键组合              | 功能                                                  |
|----------------------|-------------------------------------------------------|
| `↑` / `↓` / `j` / `k`| 移动选中项                                            |
| `Enter`              | 激活选中项（打开 / 聚焦 / 取消）                      |
| `Tab`                | 循环切换到下一个侧栏面板（Work → Tasks → Agents → Context） |
| `Esc`                | 将焦点返回输入框                                      |

## 斜杠命令面板（`Ctrl-K` 或输入 `/` 之后）

| 按键组合              | 功能                                                  |
|----------------------|-------------------------------------------------------|
| `↑` / `↓`            | 移动选中项                                            |
| `Enter` / `Tab`      | 运行 / 补全高亮的命令                                 |
| `Esc`                | 关闭面板                                              |

## 会话选择器（`Ctrl-R` 或 `/sessions`）

| 按键组合              | 功能                                                  |
|----------------------|-------------------------------------------------------|
| `↑` / `↓` / `j` / `k`| 在会话列表中移动选中项                                |
| `1`-`9`              | 打开该列表槽位对应可见会话的历史                      |
| `PgUp` / `PgDn`      | 翻页浏览历史窗格                                      |
| `Enter`              | 恢复选中的会话                                        |
| `/`                  | 搜索会话                                              |
| `s`                  | 循环切换排序方式                                      |
| `a`                  | 切换当前工作区范围与所有工作区                        |
| `d`                  | 确认后删除选中的会话                                  |
| `Esc` / `q`          | 关闭选择器                                            |

## 审批模态框（工具请求审批时）

| 按键组合              | 功能                                                  |
|----------------------|-------------------------------------------------------|
| `y` / `Y`            | 批准一次                                              |
| `a` / `A`            | 全部批准（自动批准后续调用）                          |
| `n` / `N` / `Esc`    | 拒绝                                                  |
| `e`                  | 运行前编辑被批准的输入                                |

## 引导流程（首次运行）

| 按键组合              | 功能                                                  |
|----------------------|-------------------------------------------------------|
| `Enter`              | 进入下一步（Welcome → Language → API → …）            |
| `Esc`                | 后退一屏                                              |
| `1`–`5`              | 选择语言（Language 步骤）                             |
| `y` / `Y`            | 信任工作区（Trust 步骤）                              |
| `n` / `N`            | 跳过信任提示                                          |

## v0.8.29 审计说明

- **`Shift+Enter` / `Alt+Enter` 换行现已在 Windows 上的 VSCode 中可用 (#1359)。** crossterm 的 `PushKeyboardEnhancementFlags` 命令在 Windows 上无条件返回 `Unsupported`（`is_ansi_code_supported() == false`），因此 Kitty 键盘协议的转义序列从未写入终端。没有它，VSCode 的 xterm.js 停留在传统模式，`Shift+Enter` 与普通 `Enter` 无法区分，导致输入框直接发送消息而不是插入换行。修复方案在 Windows 上直接写入 push/pop 转义序列（`\x1b[>1u` / `\x1b[<1u`），绕过 crossterm 的能力检测门控。VSCode 集成终端和 Windows Terminal ≥1.17 都支持 Kitty 键盘协议；不理解这些序列的终端会静默丢弃它们。

## v0.8.13 审计说明

- **Ctrl-S 是暂存（stash），不是历史搜索。** 在本版本中已修正——`Alt-R` 才是历史搜索。
- **移除了幻影 `Alt+Up`。** "编辑最后一条排队消息"的绑定曾在 README 中列出，但按键分发代码中从未存在。
- **输入框为空时裸方向键可滚动会话记录（v0.8.13）。** 此前 `should_scroll_with_arrows` 门控被硬编码为 false，意味着即使输入框为空，裸方向键也总是浏览输入框历史。虚拟终端（Ghostty、Codex、Kitty 协议）中的用户受影响尤其严重，因为他们无法使用 Cmd+Up / Alt+Up 快捷键。
- **可配置键位映射 (#436) 与 `tui.toml` (#437) 仍然延期。** `TuiPrefs` 结构体和加载器已存在于 `settings.rs` 中，但尚未在启动时接线。能让 `~/.codesmith/tui.toml` 覆盖单个条目的命名绑定注册表仍在待办中。
- **未发现其他损坏的绑定。** 上面列出的其他所有按键组合都能在 `crates/tui/src/tui/ui.rs`（按键事件分发）或 `crates/tui/src/tui/app.rs`（模式 + 状态转换）中找到实际的处理程序。
