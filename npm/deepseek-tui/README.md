# deepseek-tui (deprecated)

This package has been renamed to **codesmith**. Install that instead:

```bash
npm uninstall -g deepseek-tui
npm install -g codesmith
```

`codesmith` ships the same `codesmith` and `codesmith-tui` binaries plus
deprecation shims under the old `deepseek` / `deepseek-tui` names so existing
scripts keep working through the v0.8.x transition.

See [docs/REBRAND.md](https://github.com/Hmbown/CodeSmith/blob/main/docs/REBRAND.md)
for the full migration story.
